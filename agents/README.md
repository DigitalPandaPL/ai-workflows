# Agenci

Miejsce na przyszłe definicje agentów. Na tym etapie nie ma wdrożonych ani uruchomionych agentów.

Każda definicja powinna określać: rolę, wejścia i wyjścia, używane skille i ich wersje, wymagane narzędzia, zakres samodzielnych działań, budżet oraz warunki przekazania pracy człowiekowi lub kolejnemu etapowi. Konfiguracje właściwe dla konkretnego środowiska przechowuj obok przenośnego opisu roli.

Dodanie definicji nie oznacza zgody na automatyczne uruchamianie płatnych generacji ani publikację.
